# Pravadh DocSign

Site for **Pravadh DocSign** by Pravadh Labs: document generation and eSignature, built natively for Salesforce.

This is the source of the public site, [pravadhdocsign.pravadhlabs.com](https://pravadhdocsign.pravadhlabs.com). The Salesforce package is in [`../pravadh-docsign`](../pravadh-docsign).

## Run locally

From this directory:

```bash
npm install
npm run dev
```

The dev server listens on [http://127.0.0.1:47291](http://127.0.0.1:47291) and on `0.0.0.0:47291`.

## Pages

- `/` DocSign Home
- `/templates` Templates
- `/documents` Documents
- `/envelopes` Envelopes
- `/settings` Settings

Logos used by the site are in `public/brand/`. The original files outside this directory are not modified.
